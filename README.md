# Закупка для банкета — закупочный лист по техкартам

Настольное приложение для технолога кейтеринга или банкетного зала. Технолог выбирает файл меню с
техкартами и номенклатуру продуктов, указывает запас — и получает закупочный лист в Excel: продукты
сгруппированы по разделам закупки, количество округлено вверх до целых упаковок, посчитаны суммы и итог.
Полуфабрикаты (соусы, заправки) раскрываются до продуктов на любую глубину, коэффициент отхода переводит
нетто в брутто. Тот же расчёт доступен из командной строки — для планировщика задач и CI.

**Стек:** Python 3.12 · pandas · openpyxl · tkinter · decimal · argparse · pytest · ruff · mypy (strict) ·
uv · GitHub Actions (Ubuntu + Windows).

## Как считается

1. Техкарта задаёт количество нетто на одну порцию (для полуфабриката — на 1 кг выхода) и, если нужно,
   коэффициент отхода: брутто = нетто × коэффициент. Коэффициент допустим только для продуктов, которым
   это разрешено в номенклатуре, и не может быть меньше 1.
2. Блюдо раскрывается до продуктов: полуфабрикат внутри умножается на свой расход — на любую глубину.
   Цикл («Соус А → Соус Б → Соус А») находится обходом в глубину и выводится путём.
3. Количества по всем блюдам суммируются, умножаются на (1 + запас / 100) и только потом округляются
   вверх до целых упаковок (тест `test_margin_is_applied_before_rounding_to_packs`).
4. Сумма = упаковок × цена за упаковку. Весь расчёт — в `Decimal`, во float числа переводятся только при
   записи в Excel.

Пример из демо: картофеля на все блюда нужно 11,46 кг брутто, с запасом 5 % — 12,033 кг; фасовка 5 кг
→ 3 упаковки (15 кг) по 250 ₽ = 750 ₽.

## Формат входных файлов

**Номенклатура** (`examples/номенклатура.xlsx`):

- лист «Разделы»: `Раздел`, `Название в закупке`, `Порядок`;
- лист «Продукты»: `Наименование`, `Раздел`, `Ед. изм.`, `Фасовка`, `Цена за упаковку`, `Поставщик`,
  `Коэф. отхода допустим` (да/нет).

**Меню** (`examples/банкет на 40 гостей.xlsx`):

- лист «Меню»: `Блюдо`, `Порций`;
- лист «Техкарты»: `Техкарта`, `Тип` (блюдо или полуфабрикат), `Ингредиент`, `Количество`,
  `Коэф. отхода` — название и тип достаточно написать в первой строке блока, как в обычной таблице;
- необязательный лист «Своя номенклатура» — те же столбцы, что в «Продуктах»: позиция только для этого
  мероприятия (в демо — сырная тарелка от партнёра);
- необязательный лист «Параметры»: строка `Запас, %`.

Названия сравниваются без учёта регистра, лишних пробелов и разницы «ё»/«е»; числа можно писать с запятой.

## Быстрый старт

```bash
uv sync --group dev
uv run python -m banquet_calc          # окно
uv run python -m banquet_calc --menu "examples/банкет на 40 гостей.xlsx" \
    --catalog examples/номенклатура.xlsx --out output
```

```text
Готово: output\Закупка — банкет на 40 гостей.xlsx
Позиций: 31, сумма закупки: 38 460,00 ₽
```

`--margin` переопределяет запас из файла меню. При ошибках в данных команда печатает их списком и
завершается с кодом 2.

Демо: 8 блюд и 5 полуфабрикатов, 30 продуктов в 7 разделах, одна позиция из «Своей номенклатуры».
Файлы в `examples/` пересоздаются командой `uv run python -m banquet_calc.demo examples`.

## Структура

```text
src/banquet_calc/
├── models.py       # Product, Section, TechCard, Ingredient, Menu
├── normalize.py    # ключи названий, числа с запятой, «да/нет»
├── workbook.py     # чтение книг Excel; ошибки формата — все сразу, с листом и строкой
├── calculation.py  # проверки, поиск циклов, раскрытие техкарт, упаковки, итоги
├── report.py       # закупочный лист в Excel
├── service.py      # сценарий целиком — общий для окна и CLI
├── gui.py          # окно tkinter, расчёт в фоновом потоке
├── cli.py          # командная строка
├── settings.py     # настройки окна в JSON
└── demo.py         # генератор демо-файлов
tests/              # 27 тестов
examples/           # демо-меню и номенклатура
```

## Как проверялось

Windows 10, Python 3.12 (uv):

- `ruff check`, `ruff format --check`, `mypy` (strict, 12 файлов) — без ошибок;
- `pytest` — 27 тестов: расчёт (13), разбор книг (6), окно и настройки (5), отчёт и CLI (3); тест окна
  создаёт настоящее окно tkinter;
- демо через CLI — 31 позиция на 38 460 ₽, строка картофеля пересчитана вручную.

Не проверялось: workflow GitHub Actions описан (матрица Ubuntu + Windows), но в Actions не запускался;
на Linux без дисплея тест окна пропускается.
